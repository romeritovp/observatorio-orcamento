# Como fazemos {#topo}

## simples

De onde vem cada número, como ele é calculado, que escolhas fizemos e o que ainda não sabemos. Você pode refazer as contas com uma calculadora.

## tecnico

Fontes, método de cálculo, decisões de tratamento dos dados e limitações conhecidas, com as referências e os códigos de conta. Todos os números desta página saem dos mesmos JSON publicados que as outras telas usam.

## formulas

As fórmulas de cada número do site, para auditoria. Cada uma traz a origem de cada termo (arquivo publicado e campo) e um exemplo com os números publicados {{exemplo.do_uf}}. Os exemplos são preenchidos pelas mesmas funções que desenham as telas, e um teste automático os confere contra um cálculo independente (o gabarito feito em Python e, na tendência, o pacote estatístico statsmodels). Os arquivos estão na pasta `data/` do site.
